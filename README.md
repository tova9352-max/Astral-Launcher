# Astral Launcher

Launcher Android nativo con estética Liquid Glass oscura y acentos violeta.

## Compilar
El workflow de GitHub Actions compila automáticamente un APK debug al hacer push a `main` o al ejecutarlo manualmente.

El APK aparece en **Actions → Build Astral Launcher → Artifacts**.

- Application ID: `studio.astral.launcher`
- Versión inicial: `0.1.0`
